# Cozy Boba Notes & Chill

A simple one-page site for Boba Bash. It's a cozy little corner to write notes, track your water and take breaks.

## What's on the page

- Daily notes box
- Water tracker (8 glasses)
- List of chill sounds
- Break reminder

## Built with

- HTML
- CSS

No frameworks and no JavaScript.

## Files

- `index.html` - the page
- `style.css` - the styling
